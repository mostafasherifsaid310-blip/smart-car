# Smart Car

Smart Car is a Django-based web application designed to manage cars, maintenance, spare parts, technicians, appointments, authentication, and AI-assisted features.

## Features

- User authentication and authorization
- Car management
- Maintenance management
- Spare parts management
- Technician management
- Appointment management
- Dashboard
- AI Agent integration
- PostgreSQL database support

## Technologies

- Python
- Django
- PostgreSQL
- Google GenAI
- psycopg
- python-dotenv
- Git & GitHub
